# A股技术指标失效检验（临时研究任务）

本目录用于运行一次可审计的全市场历史检验。研究结果不构成投资建议。

## 数据

- 数据集：`ellendan/a-share-21` 的自动转换 Parquet 分支。
- 期间：2021-01-01 至 2025-02-27。
- 范围：上海、深圳 A 股；不含北交所。
- 数据字段包括 OHLC、成交额、历史 ST 标记、停牌标记、涨跌停价、上市日期等。

## 逐日股票池过滤

1. 剔除历史时点 ST 股票；
2. 剔除当日停牌股票；
3. 过去 60 个市场交易日至少有 54 个有效成交日；
4. 上市至少 120 个市场交易日；
5. 20 日成交额中位数高于当日全市场第 20 百分位；
6. OHLC 与成交额必须有效。

## 回测

- t 日收盘计算信号；t+1 收盘建仓；t+h+1 收盘退出。
- 买入日一字涨停视为无法成交，收益按现金 0 计。
- 测试 14 个趋势、反转、量价与波动率信号，持有期为 1、5、20 日。
- 分别测试全市场、主板、创业板、科创板和上涨/下跌/震荡状态。
- 使用样本外区间 2023-01-01 至 2025-02-27 确认。
- 使用 Newey–West 统计检验与 Benjamini–Hochberg FDR 控制多重检验。

工作流只在本临时研究目录或自身工作流发生变化时运行。
